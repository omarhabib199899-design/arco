# موقع أركو للمقاولات العمومية والتسويق العقاري

موقع PHP + MySQL ثنائي اللغة (عربي / إنجليزي) مع نظام حجز مواعيد ولوحة تحكم.

---

## 1) التشغيل محليًا (XAMPP)

1. شغّل **Apache** و **MySQL** من XAMPP Control Panel.
2. افتح `http://localhost/arco/install.php` مرة واحدة لإنشاء قاعدة البيانات والجداول.
3. افتح الموقع: `http://localhost/arco/`
4. لوحة التحكم: `http://localhost/arco/admin/`
   - المستخدم: `admin`
   - كلمة المرور: `Arco@2026`
5. **احذف `install.php` بعد التثبيت.**

---

## 2) الرفع على الاستضافة (cPanel)

1. ارفع كل الملفات إلى `public_html` (أو مجلد فرعي).
2. من **MySQL Databases** في cPanel:
   - أنشئ قاعدة بيانات (مثال: `username_arco`)
   - أنشئ مستخدمًا وأضفه للقاعدة بكل الصلاحيات
3. افتح `includes/config.php` وعدّل:
   ```php
   define('DB_NAME', 'username_arco');
   define('DB_USER', 'username_dbuser');
   define('DB_PASS', 'your-password');
   ```
4. افتح `https://yourdomain.com/install.php` مرة واحدة ثم **احذف الملف**.
5. غيّر `ADMIN_USER` و `ADMIN_PASS` في `config.php`.

---

## 3) البيانات التي يجب تعديلها قبل الإطلاق

كلها في ملف واحد: **`includes/config.php`**

| الثابت | الوصف |
|---|---|
| `SITE_PHONE` / `SITE_PHONE2` | أرقام الهاتف الظاهرة في الموقع |
| `SITE_WHATSAPP` | رقم الواتساب بصيغة دولية بدون `+` (مثال: `201001234567`) |
| `SITE_EMAIL` | البريد الإلكتروني |
| `SITE_ADDRESS_AR` / `SITE_ADDRESS_EN` | العنوان |
| `SITE_MAP` | رابط الموقع على خرائط جوجل |
| `SOC_FACEBOOK` / `SOC_INSTAGRAM` / `SOC_LINKEDIN` | روابط السوشيال |
| `WORK_START` / `WORK_END` | ساعات العمل المتاحة للحجز (24h) |
| `WORK_OFF_DAY` | يوم الإجازة الأسبوعي (`5` = الجمعة، `0` = الأحد) |
| `NOTIFY_EMAIL` | بريد يصلك عليه إشعار بكل حجز جديد (اتركه فارغًا للتعطيل) |
| `ADMIN_USER` / `ADMIN_PASS` | بيانات دخول لوحة التحكم |

> خريطة صفحة «تواصل معنا»: عدّل الـ `iframe` في آخر `contact.php` ليشير لموقع المكتب الفعلي.

## 5) تعديل النصوص

كل نصوص الموقع في `lang/strings.php` بصيغة:

```php
'hero_title' => ['ar'=>'نبني القيمة… ونصنع الثقة', 'en'=>'We Build Value… We Create Trust'],
```

لإضافة عمل جديد لسابقة الأعمال، أضف سطرًا في `lang/projects.php`:

```php
['r'=>'nc','c'=>['ar'=>'اسم العميل','en'=>'Client'],
          's'=>['ar'=>'الموقع','en'=>'Location'],
          'w'=>['ar'=>'بيان الأعمال','en'=>'Scope']],
```

`r` = المنطقة: `nc` الساحل الشمالي | `cc` القاهرة والعاصمة | `ot` أخرى.

### إضافة اعتماد جديد

1. ضع صورة المستند في `assets/img/approvals/` باسم إنجليزي، مرتين:
   `اسم-الملف.jpg` (نسخة كاملة، العرض الأقصى ~1700px) و `اسم-الملف-thumb.jpg` (مصغّرة ~620px).
2. أضف عنصرًا في `lang/approvals.php`:

```php
['img'=>'اسم-الملف', 'g'=>'ha',
 'client' =>['ar'=>'جهة الاعتماد','en'=>'Issuer'],
 'project'=>['ar'=>'المشروع','en'=>'Project'],
 'doc'    =>['ar'=>'وصف المستند','en'=>'Document description'],
 'ref'=>'رقم الطلب', 'date'=>'01-01-2025',
 'by'=>['ar'=>'الاستشاري','en'=>'Consultant'],
 'status'=>['ar'=>'معتمد','en'=>'Approved']],
```

`g` = مجموعة الفلترة: `ha` حسن علام | `gov` الهيئة الهندسية | `morshedy` معمار المرشدي | `mfg` شهادات المصانع.
لإضافة مجموعة جديدة عدّل `approval_groups()` في `includes/functions.php`.
`status` اختياري (ضع `null`)، والعنوان في البطاقة هو `client` ويفتح صورة المستند كاملة عند الضغط.

## 7) نظام الحجز

- العميل يملأ النموذج في `booking.php` ويحصل على **رقم مرجعي** (مثال `ARC-261011-8E4CA`).
- الطلب يُحفظ في جدول `appointments`.
- التحقق التلقائي: لا يقبل تاريخًا ماضيًا ولا يوم الإجازة الأسبوعي، ويتحقق من الهاتف والبريد.
- من لوحة التحكم: تصفية حسب الحالة، بحث، تغيير الحالة (جديد / مؤكد / تم / ملغي)، ملاحظة داخلية، مراسلة واتساب بضغطة، حذف.
